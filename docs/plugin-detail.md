# 派活模型设置 · Subagent model settings

分别给性价比模型和专家模型排序，写下什么任务适合用它。主模型可按用途选择起点，自动换模型时只向组内下一位尝试。到「子代理」设置单独授权要用的模型。

Order the cost-effective and expert models, and write a short purpose for each. The main model can pick a starting point; automatic switching moves to the next model in that group. Allow the models separately in Subagent settings.
